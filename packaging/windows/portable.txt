Varos portable mode

While this file sits next to vectorcraft.exe, Varos keeps its preferences, swatch and
graphic style libraries, added fonts, crash-recovery files and logs in the VarosData folder
beside it, and writes nothing to %APPDATA%. Copy the whole folder to move Varos with its
settings. The first time VarosData is created, any settings already in
%APPDATA%\Varos are copied into it; the originals are left where they were.

Keep this folder somewhere only you can write to: whoever can write here decides your settings,
including the plug-ins and fonts folders Varos loads from, and the Data Recovery copies of
your unsaved documents are kept here too.

Delete this file to use the normal per-user settings folder (%APPDATA%\Varos) instead.
If VarosData can't be written (for example on a read-only drive), Varos logs a
warning and uses %APPDATA%\Varos instead.
