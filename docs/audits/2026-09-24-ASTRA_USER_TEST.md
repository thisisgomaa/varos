# Astra — macOS designer-perspective hand-test

**Finding counts: P0 1 · P1 3 · P2 6 · P3 1.** No application crash or crash dialog observed. The P0 is the already documented unsaved-quit gap, not a newly discovered crash. Severity reflects user impact, not whether a gap was previously known.

## Method and scope

Tested the installed `/Applications/Varos.app` on 24 September 2026 using screen inspection, mouse actions, keyboard shortcuts and Varos's native macOS dialogs. “Astra” is the requested Illustrator-experienced design-review perspective; this is a Codex computer-use audit, not a claim of a human employment history. Illustrator expectations below are workflow comparisons, not a contemporaneous side-by-side Illustrator test.

Session: approximately **14:45–15:32 Cairo (11:45–12:32 UTC)**. The first pass through STATUS's batch-1 list preceded free exploration. Exploration and targeted retests occupied approximately **35 minutes, 14:57–15:32 Cairo**, including capture and input-tool recovery. High-zoom items initially impeded by shortcut behavior were revisited during exploration.

The composition used a closed Pen curve, an ellipse subtraction to form a crescent, a rotated diamond, three aligned/distributed dots, grouping and layer visibility/locking. A second 1200 × 1200 artboard used a dark teal background, orange 80-unit circular stroke and a cream Pen-drawn four-point star. Numeric transforms, rotation/scale, hexadecimal colours, alpha, artboard duplication/renaming and repeated pan/fit/actual-size operations were exercised. Temporary extreme-coordinate geometry was undone before saving.

Final working file: `/tmp/astra/test.vrs`. Batch fixture: `/tmp/astra/batch1.vrs`. The final file was saved, the app quit and relaunched, and the file reopened through **File/Open**, with both compositions visibly intact. A disposable unsaved white square was then lost on quit/reopen, reproduced twice. The final saved composition excludes that square.

Only this report was added to the repository. No source code, build settings, tests or dependency files were edited. Screenshots are uncommitted outside the repository under `/tmp/astra/shots/`, captured with `screencapture -x` (one attempt also used a capture delay). Some include the desktop behind Varos; only the Varos window is evidence. Captures that missed Varos entirely were discarded. OS window shadows and the computer-use pointer glow are not attributed to Varos.

**Limits:** the input API cannot hold Space/Option while moving the pointer or provide a true hover-only sweep. Its pointer overlay prevents reliable Retina cursor appraisal. No complex masked fixture was available through the tested UI. Snap/guide toggles and rulers were exercised, but precise snapping tolerances and guide dragging were not comprehensively validated. Several `noWindowsAvailable` and ScreenCaptureKit errors were computer-use failures; the app was still accessible and they are excluded from crash counts. No permission prompt was answered. No other application was operated.
