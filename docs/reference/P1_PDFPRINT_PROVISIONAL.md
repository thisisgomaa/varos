- PDF defaults retain the historic export bytes. Explicit Print/Press/Smallest presets choose image ppi 150/300/72 and stream compression; Press enables each artboard's document bleed. Custom ppi accepts 1–9600. No raster content exists yet: an export report records this rather than pretending to resample vectors. Colour bars are refused until colour management.
- Explicit settings write TrimBox, BleedBox and MediaBox with a 24 pt marks margin when needed. Artwork is clipped to BleedBox; thin K crop/registration lines and Helvetica page information stay in the margin. Native VRS saves and Phase 2 stroke caps/joins remain untouched.
- CLI: `export-pdf INPUT --out OUTPUT [--preset print|press|smallest|custom] [--ppi N] [--marks crop,registration,page_info|none] [--bleed POINTS]`. `print` uses the same arguments and prepares a PDF headlessly; it never prints. Explicit options return a report in JSON; legacy CLI defaults keep their response shape.
- Bridge `export_pdf` accepts `options` only under API 1.2. Options contain `preset`, `image_ppi`, `compress_streams`, `boxes: {bleed, bleed_override?}` and `marks: {crop, registration, page_info, colour_bars}`. Preset-only JSON applies preset defaults before overrides.
- File > Print / Cmd+P uses the last PDF scope/options for that tab, otherwise the default scope. macOS uses the permitted `/usr/bin/open -a Preview` fallback: the user then chooses File > Print in Preview. This does not claim a direct NSPrintOperation panel. The temporary PDF is retained for reprinting. Windows has a disabled row with a reason. Print preparation/handoff are separate functions; tests call preparation only.
- Copy and Cut capture fresh sources using core selection rules (including direct path selection; anchor-only selection captures nothing). Cut excludes locked sources before any publication. They publish `org.varos.clipboard` first (serialized detached Clipboard), then `com.adobe.pdf`, `public.svg-image`, `public.png`. Public vector bytes use the export writers; PNG is transparent at 2x selection bounds with explicit allocation limits. The internal editor clipboard remains the lossless Varos paste source. Nonpainting selections still publish the lossless flavour; oversized selections omit PNG but retain vector flavours. Desktop notices and API 1.2 replies report actual published types and omission reasons. Publication failure prevents deletion. NSPasteboard is behind a trait, and its test implementation never contacts the system pasteboard. Windows retains internal Copy/Cut.
- API 1.2 host verbs `print`, `copy`, `cut` use the revision/idempotency guards. Print accepts scope/options; Copy/Cut use current selection. MCP discovery is opt-in via `tools/list` parameters `api: "1.2"`; legacy discovery/capabilities stay unchanged. Attached CLI can call these verbs with JSON API 1.2 arguments.
- Headless CLI `clipboard-out INPUT --ids path:N,path:M --out NEW_DIRECTORY` writes the four flavours for inspection using the same vector/PNG builders, without touching a real clipboard.
