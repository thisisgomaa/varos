# خطة Varos الحالية

دي نقطة البداية للشغل الجديد. [STATUS](foundation/STATUS.md) يقول إيه الموجود فعلًا، والصفحة دي تحدد كل جزء رايح فين وإزاي نعتبره خلص. تفاصيل التنفيذ والاختبارات تفضل في أمر العمل الأصلي؛ السجل القديم محفوظ، لكنه مش قائمة مهام تتنفّذ تاني.

## الحالة بالمختصر

- الأساس الحالي مستمر: Rust + Winit/Egui/WGPU، أربع crates، والـcore مستقل عن الواجهة.
- Mac هو البناء الرسمي حاليًا؛ Windows فحص توافق كود فقط.
- الرسم والتبويبات والحفظ الأساسي شغالين. صفحة البداية وHome وRecent اتربطوا على فرع العمل؛ الحفظ الآمن وكتابة نسخ الاسترجاع اتربطوا كمان؛ عرض النسخ واسترجاعها F2 اتنفذ واختباراته نجحت؛ تجربة الاسترجاع في النافذة والتصدير الكامل لسه باقيين.
- صيغة v2 بتتكتب فعلًا، والتحقق الدلالي S5-C وقراءة PDF المحدودة S5-D اتنفذوا على فرع العمل ولم يُراجعوا أو يُدمجوا بعد؛ اختبارات وملفات S5-E الثابتة اتجهزت؛ لا ملفات شخصية حسب المالك والفحص، وتجربة النافذة النهائية باقية.
- دعم الماسكات موجود في الموديل والرندر وPDF؛ إنشاء الماسك من الواجهة لسه ناقص. قص الأرتبورد متاح، ودي ميزة مختلفة.
- نظام الواجهة عنده مسودة v2 محددة الحدود وجدول رد على المراجعات؛ لم تُنفّذ أو تُعتمد بمراجعة مستقلة بعد. المسودة القديمة محفوظة في history. أساس الخطوط U0-A منفذ؛ [قيد العربي ونتائج التجربة](foundation/work_orders/UI_U0_A_FONTS.md) صريحة قبل تعميمه.

## معنى الحالات

| الحالة | معناها |
|---|---|
| مدموج | الكود موجود في `main`؛ التجربة البصرية قد تظل مطلوبة بشكل منفصل. |
| وحدة جاهزة | منطق واختبارات موجودين، لكن دورة الاستخدام في التطبيق لسه ناقصة. |
| ناقص | متطلب واضح له تنفيذ أو ربط لم يكتمل. |
| مقترح | محتاج تصميم/مراجعة أو قرار؛ مش تكليف ببنائه كله. |
| مؤجل | محفوظ للمستقبل، ومش شرط للمرحلة الحالية. |

## القرارات السارية واللي لسه مفتوح

**قرارات اتاخدت بالفعل:** ADR-0008 لصيغة الملفات مقبول؛ Home بدل burger على Mac؛ icons بدل نصوص الأزرار؛ Plex Sans/Mono/Arabic مع تجربة bidi للأسماء؛ إزالة glide/ease/glow مع بقاء direction bar؛ حالات on حسب mockup؛ FAINT→MUTED ومقاسات QW6؛ حفظ توزيع البانلات مؤجل وReset Workspace من Window فقط؛ ملف v1 ذو ماسك مكسور يفتح بتحرير الماسك مع notice؛ تصدير مستند اسمه `.pdf` يستخدم `<name> export.pdf`. التفاصيل ومصدر كل مجموعة في [تسوية UI](specs/UI_SYSTEM.md) و[أمر S5](foundation/work_orders/DFS_S5_FORMAT_V2.md).

**لسه مفتوح، من غير إعادة فتح كل الأسئلة القديمة:**

- P12: سلوك حذف نقطة بالقلم، وP21: حالات التحديد/الماسك؛ تُحسم عند تجهيز القطعة المعنية، بتوصيف واضح للأثر.
- مصير عمل `codex/p6-header` القديم قبل استخراج F5: نتحقق من المحتوى وما استُبدل، ولا نمسح فرعًا أو worktree من الخطة وحدها.
- تعديل عقد glide يحتاج ADR لاحقًا وفق ADR-0006. ADR-0009 كان رقمًا مقترحًا؛ تحقق من الرقم المتاح وقت الكتابة. الدراسات القديمة التي طلبت ADR-0008 لا تملك هذا الرقم الآن.
- طرح التبعيات المقترح، تفاصيل look غير المحسومة، توقيع/توزيع الإصدار، وتجربة Windows الحقيقية تبقى بنطاقها وقرارها.

## متطلبات محفوظة للمستقبل

دي مش مهام ضاعت أو اتلغت، لكنها خارج دفعة الملفات الحالية:

- [الماسكات](MASKS_PLAN.md): gestures والتحديد والتداخل، مع إصلاح حدود الرندر قبل الادعاء باكتمالها.
- Live Corners، Curvature، Appearance متعدد الطبقات، Stroke كامل، Gradients، PNG/SVG export وSVG import: تفاصيل backlog في [الخريطة المؤرخة](foundation/PLAN_MAP_2026-09-23.md) و[الخطة التفصيلية القديمة](history/DETAILED_ROADMAP.md). تُعاد صياغة القطعة المطلوبة على الكود الحالي، لا تُنفّذ الخطة التاريخية بالكامل.
- النص العربي: تجربة تقنية محدودة للتحرير/الاتجاه/الحفظ/التصدير قبل الالتزام بمحرك كامل؛ رؤية المنتج لا تعني إنه موجود حاليًا.
- icon library والـpicker وباقي التلميع تحت نظام الواجهة؛ نافذة Mac تتذكر مقاسها، screen eyedropper، وFit الذي يتجنب الشريط متابعات محفوظة.
- MCP والإضافات والمتصفح/cloud والتحديثات: دراسات وسياسات مستقبلية، لا تنفيذ ضمن هذه الدفعة.
