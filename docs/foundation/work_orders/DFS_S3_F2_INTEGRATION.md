# DFS S3-F2 — Recover saved copies after relaunch

2026-09-27, baseline `6f50eab`. Implements [F2](DFS_S2_S3_START_RECENTS_RECOVERY.md) on top of F1's single worker. Launch cleanup/scan, explicit loading and discard run on that worker. Start remains the home for recovery choices; a neutral strip in the editor leads there. Later hides the reminder for this run and retains copies. Damaged/newer copies remain listed with their reason; busy actions cannot duplicate work.

A recovered document is pathless and dirty even when empty, carries the claimed recovery id, and defaults Save As to `<name>-recovered.vrs` in the original folder. Recovery does not change the original file or Recent. The host settles the outgoing editor before installing a completed load. Explicit discard asks with Cancel as the default; successful Save As or committed close/quit retires the adopted copy through F1. A fallback to the previous generation is explained in the recovered-document strip.

Tests stay CPU-only with isolated storage and fake dialogs/clock. Cover orphan claims, fallback, failed/canceled discard, Later/relaunch, original-file bytes/mtime, dirty/pathless adoption, safe Save As defaults and retirement. Keep the existing warm-black tokens and control kit; no new visual world or dependencies. User-authorized session-end review supersedes per-piece manual acceptance; unverified native presentation must remain explicit.
