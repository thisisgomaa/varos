  • Radii 3 px on controls, 8 px on panels, menus, cards.
  • No shadows. Popovers separate by a hairline only.
  • Rows 24 px; fields 20 px; labels 11 px muted; group heads 10 px caps.
  • Icons first (owner, 2026-10-19): any control with an obvious icon is an icon; tooltips carry the words; text stays only where no icon reads clearly.
  • Text choices (font-menu segments, filter chips, list rows) select in azure, as in the approved font menu.
  • Icon choices and toggles (alignment, Direction, Kashida, Hide, As letters) light up: dark well, bright icon, no azure.
  • Mixed: nothing lit, present values tinted with Hover, numbers read "–".
  • Arabic always dir="rtl", right-aligned, in the font it names when shown as a sample.
  • Type Inter / system-ui; decoration comes from type weight and colour only.
