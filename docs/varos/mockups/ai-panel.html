7Rules this panel adds to the kit

  • Orange is the agent. Dot on receipts, busy badge on the rail, outline on the canvas. Never azure, never on human actions.
  • Azure is still a scalpel. Only the focused prompt box or field gets an azure border.
  • One primary per card. Light fill, dark text (Run, Generate, Edit, Keep). Everything else is a surface button.
  • Receipts are one line. verb · target · result, 20 px, ellipsis at the card edge; running step has a hollow dot.
  • Refusals are notes. Muted 10.5 px text with a 12 px glyph and the code name. No modal, no prompt, no sound.
  • No credential UI of ours. Sign in runs the CLI's own browser login; keys sit in keys.toml (0600), never in documents.
  • Cost is always visible next to the result it paid for, as the provider reported it.
  • Nothing is replaced silently. Image edits land beside the source; a run undoes in one click.
  • Choice tracks reuse the kit. Provider, scope, size and mode are the kit's 24 px track with a lit well.
  • Arabic first. Prompt box flips to RTL with Geeza Pro on Arabic input; receipts stay LTR, quoted Arabic stays RTL inside.
