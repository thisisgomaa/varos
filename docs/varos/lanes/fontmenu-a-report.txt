Menu, top to bottom
1. Search field; at its right Auto / Aa / shaped أب sample segments with tooltips.
   Auto follows selected text. Aa always uses the generic Latin sample, including
   with Arabic, Japanese, Thai or Cyrillic selected. أب uses the Arabic sample in
   Arabic-capable families; other families retain their non-Arabic selected sample.
   With no Arabic-capable family installed, the glyph segment has a translated
   Arabic text fallback. Sample mode survives closing/reopening with menu state.
2. Full-width, exclusive All / Arabic / Latin / Japanese / Thai script switch.
   Arabic uses the existing cmap/joining capability detection. Other script
   matching remains upstream's (including its broad Latin classification).
3. Only under Arabic: All Arabic / Naskh / Kufi / Ruq’ah / Diwani / Thuluth /
   Modern Sans style chips. An available matching face shapes its Arabic name;
   otherwise the translated Latin label appears. Latin tooltips identify styles.
   Labels use the existing bounded, background sample cache and wasm frame budget.
4. One horizontally scrolling kind strip: star / Any Kind / Serif / Sans /
   Rounded / Script / Mono / Decorative. No wrapping into more kind rows.
5. Existing family/style rows: name, Arabic name when available and space permits,
   per-mode sample, AAT marker and star. Existing selection/preview behavior kept.
