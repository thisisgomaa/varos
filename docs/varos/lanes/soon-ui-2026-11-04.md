## Implementation

- `varos/soon.rs`: shared catalogue, outlined tag, disabled panel/menu/button rows, hover-only
  Dieline submenu, Preferences content, Print rules tab, press-condition row and template diagrams.
- `varos/ai.rs`: Ask / Images / History, existing Getting started and Crop Image command mirrors,
  licensed bundled sparkles icon in a neutral right-strip toggle.
- `varos/theme_components.rs`: Soon metrics alongside existing typography and surface roles.
  Ink and borders use Tokens; no azure or shadows in Soon painting.
- Small marked upstream hooks connect these surfaces. Native menu presentation is adapted in
  `apps/vectorcraft/src/varos_soon_menu.rs`; the platform owns native menu typography.
- New unified workspaces open AI at the right. Fresh normal startup activates AI in the existing
  right dock before the host restores saved preferences. Studio receives the default only in its
  fresh-workspace branch. Both presenters have a strip mirror independent of saved owners.
  Historical shell defaults, v1/missing-strip recovery and classic-layout migrations exclude AI
  unless explicitly saved; merely drawing either mirror never creates a panel owner.

## Known differences

- Some row glyphs in the HTML are not in the existing bundled icon catalogue. Existing licensed
  glyphs are reused (message-circle, lock, library, menu, monitor, shapes, maximize-2, settings, frame),
  with no new assets. AI's strip icon is the bundled Lucide sparkles glyph.
- macOS native menus use system text “— Soon” instead of an egui outlined badge. The native
  adapter assigns the same tooltip and disables Soon items, including Dieline. A disabled native
  submenu cannot expand; the full hover submenu is available in the in-window egui menu. Native
  appearance/tooltips cannot be visually verified without an owner-run window.
- Software captures and automated input cannot substitute for the owner's native acceptance.
- Full-editor captures retain existing workspace columns and contextual/control bars. Studio
  keeps Properties/Layers beside AI; the legacy shell keeps AI with Properties in a tab group.
  The mockup simplifies this surrounding editor context. The capture document uses authored
  test geometry, not the mockup's poster; no placeholder artwork was added to the product.
