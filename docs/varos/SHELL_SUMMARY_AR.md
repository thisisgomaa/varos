# ملخص الواجهة الجديدة — صفحة واحدة (2026-10-27)

> التفاصيل بالإنجليزي في `SHELL_DESIGN_NOTES.md` و `NEW_SHELL_PLAN.md`.

## الفكرة في سطر
شاشة بليندر (بوكسات مستقلة تقسمها وتبدّلها + Workspaces) + نظام بانلات إليستريتور (شرايط أيقونات وflyouts وعائم، خفيف ورايق) + قوائم إليستريتور التسعة.

## الهيكل
1. **فوق:** القوائم التسعة (File · Edit · Object · Type · Select · Effect · View · Window · Help) + شريط الـ Workspaces (Design · Typography · Print · +).
2. **البورد (الكانفس)** بوكس واحد كبير. **حوافه بس** فيها شرايط أيقونات: التولز على حافته الشمال، أيقونات البانلات الصغيرة على حافته اليمين.
3. **باقي البوكسات عادية:** كل بوكس فيه بانل أو أكتر كتابات (Layers | Artboards)، (Properties | Color | Swatches). تقسمه، تسحب تاب منه لبوكس تاني، تقفله.
4. **الفواصل** بين البوكسات للتحجيم بس. مفيش أيقونات على الفواصل.
5. **تحت:** شريط الحالة.

## الشريط (أيقونات) — زي إليستريتور بالظبط
- **حالتين بس:** أيقونة، أو أيقونة + اسم (`<<` / `>>` بيبدّل).
- الأيقونات في **مجموعات**، كل مجموعة ليها نقط مسكة صغيرة فوقها وفاصل رفيع تحتها.
- **ضغطة على الأيقونة** = البانل تفتح كـ flyout جنب الشريط. ضغطة تاني تقفل. أيقونة تانية تبدّل. واحدة مفتوحة في المرة. `>>` في الـ flyout ترجّعها أيقونة.
- **الشريط يقدر يعوم** لوحده في أي مكان (× و `>>` ونقط تحجيم).
- **أيقونة واحدة تتسحب برّه** = شريط عائم بأيقونة واحدة. ضغطة على الأيقونة = flyout والأيقونة فاضلة. `>>` = بانل كاملة عائمة والأيقونة تختفي. `<<` ترجّعها.

## الجروب (بانلات بتابات)
- جروب = بانل واحدة ظاهرة في المرة، التابات بتبدّل. الأسماء بتتقصّر لما الجروب يضيق، والتاب النشط مضوّي وأعرض.
- تسحب تاب وترميه على صف تابات جروب تاني = ينضم. تسحبه برّه = بانل عائمة لوحدها.
- **دبل كليك على التاب** = يتطوي لشريط العنوان بس. دبل كليك تاني يفتح.
- الـ `◇` الصغيرة جنب اسم التاب النشط = "أوبشنز أقل / أكتر" بتاعة البانل نفسها.

## السحب والإفلات (القاعدة الذهبية: شايف النتيجة قبل ما تسيب)
- اللي بتسحبه = **شبح صغير** ماشي مع الماوس.
- **خط أزرق** هو الإشارة الوحيدة: خط طولي بطول حافة الشاشة/العمود = "هيبقى عمود جانبي"، خط قصير بين المجموعات أو بين التابات = "هيدخل هنا".
- Escape يلغي. مفيش حاجة بتتكرر أو بتضيع: كل بانل ليها صاحب واحد.

## الإحساس (أحمد 2026-10-27: «الأهم دلوقتي هو الإحساس والأنيميشن والسيستم نفسه»)
- **الاستجابة فورية** زي إليستريتور، مع **حركة خفيفة جدًا وسريعة** (انزلاق قصير للـ flyout وللبانل لما تتدوك) يحكم عليها أحمد بإيده.
- **الألوان مهمة بس تيجي بعد السيستم:** واضحة، مينيمال، مودرن. نبدأ بألوان فاروس الحالية وجولة ألوان مستقلة بعد ما السيستم يقف.
- مسطّح: درجتين رمادي، خطوط 1px، أيقونات أحادية، عنوان التاب بولد صغير. الـ chrome الوحيد: `<<` `>>` × ونقط المسكة.

## البانلات
- Properties محرر مهم لوحده (أقسام تتطوي وتترتب، يتبع التحديد أو يتثبّت على عنصر).
- Color = البيكر v3 بتاعنا. AI panel = بانل مستقلة في القائمة.
- الـ 42 بانل الحاليين كلهم متاحين من قائمة Window ومن أيقونات الشريط.

## الترتيب (كل مرحلة تجرّبها بإيدك قبل اللي بعدها)
1. **الهيكل:** سويتش في Preferences → بورد + Layers + Properties كبوكسات، فواصل تتحجّم، ألوان فاروس. الباقي زي ما هو.
2. **الشرايط والـ flyouts** على حواف البورد (أيقونات البانلات بالمجموعات الحالية).
3. **السحب:** شبح + خط أزرق + عائم + دمج تابات + أيقونة واحدة + دبل كليك.
4. **Properties** كمحرر بأقسام + Workspaces + حفظ التخطيط.
5. **الشكل النهائي** (الشريط العلوي، شريط الحالة، التولز على حافة البورد).
6. شيل النظام القديم بعد موافقتك.
