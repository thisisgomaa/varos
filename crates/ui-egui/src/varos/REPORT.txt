  2.3.0. It subsequently appeared in the cache during the supplied prebuild; this
  agent did not fetch dependencies or change CARGO_TARGET_DIR.
- Most early elapsed time was shared build-lock waiting, then cold UI-test
  dependency compilation. The existing target directory was preserved.
- A hotspot closure initially needed an explicit usize index type (E0282); fixed.
- NSApplication and NSWindow also require AppKit's NSResponder feature. The first
  test invocation resolved its graph before that feature was added, then waited
  on the lock and failed E0432. A fresh invocation with the final manifest passed.
- Rust 1.98 Clippy required array chunks and checked alpha division. Both were
  fixed in the new module; build, all tests, Clippy, WASM and fmt were rerun.
- Merely setting an NSCursor is insufficient while winit owns a cursor rectangle;
  the scoped rectangle lease handles that without unconditional per-frame sets.
